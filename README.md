# Sales & Revenue Analysis Dashboard

## Project
Interactive dashboard for analyzing sales and revenue data.

## Features
- Total Revenue, Total Profit, Orders and Average Order Value KPIs
- Monthly revenue trend
- Revenue by category
- Revenue by region
- Top 10 products
- Interactive filters for region, category, product and month
- CSV source dataset

## Platform
HTML/CSS/JavaScript dashboard designed to be hosted with **GitHub Pages**.

## How to publish
1. Create a new public GitHub repository.
2. Upload `index.html`, the `data` folder and this `README.md`.
3. Open **Settings → Pages**.
4. Under Build and deployment choose **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save and wait for the Pages URL to appear.
7. Paste that URL into the assignment's **Submission Link** field.

## Dataset
The included `data/sales_data.csv` is an illustrative academic dataset generated for this dashboard. If your instructor provided a real dataset, replace the CSV and update the dashboard data.

## Business Questions
- What is total revenue and profit?
- Which products generate the most revenue?
- Which categories and regions perform best?
- How does revenue change by month?
- How does performance change after applying filters?

## Expected Learning Outcomes
Data preparation, KPI tracking, data visualization, interactive filtering, business insight generation, and dashboard publishing.
